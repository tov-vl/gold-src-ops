# v2.115 - Minute-precision credential expiry

## Scope and compatibility

This R1 API/Web slice extends the existing Operator-only register with nullable
`expiresAtMinuteUtc`, exactly `yyyy-MM-ddTHH:mmZ`. A minute entry leaves the
existing exact-second `expiresAtUtc` null. The two representations are mutually
exclusive; malformed, ambiguous, unverified or future-verified metadata remains
Unknown. Four fixed purposes, bounded projection, no-store and server-side BFF
bearer handling remain unchanged.

Minute warnings use the start of the recorded UTC minute. The existing exact
deadline/7/30-day comparisons and rounded-up remaining days apply to that
conservative boundary. The page renders no invented seconds and explains that
warnings can appear up to one minute early. Its reached-minute label does not
claim that access has failed. Verification time remains the actual provider
check; Refresh changes only evaluation time. Exact-second Grafana records retain
their existing behavior.

New Web accepts an old payload without the minute field. Old Web requires a
non-null exact-second expiry before displaying a known state, so minute entries
degrade to Unknown instead of pretending that `:00` was provider evidence.
The serialized legacy shape is explicitly checked. Mixed-version runtime
injection is not required or claimed.

Infrastructure reads optional `CredentialExpiry:<section>:ExpiresAtMinuteUtc`
alongside the existing fields. Production Compose adds only the fixed B2
ArchiveReader/ArchiveWriter mappings from
`GOLDSRCOPS_ARCHIVE_READER_EXPIRY_MINUTE_UTC` and
`GOLDSRCOPS_ARCHIVE_WRITER_EXPIRY_MINUTE_UTC`. Empty minute values preserve
second-only behavior. When choosing a minute, clear the same entry's exact-second
field. Private provider dates remain outside Git.

No database migration, key rotation, provider mutation, new credential, secret
transport, permission, scheduler change, monitoring rule, email, game or agent
change is included. Rollback restores the accepted v2.114 API/Web digests and
original env/Compose. No durable-state migration exists.

reached-minute text, no invented seconds, no-store, refresh and unavailable

Remaining comma notes preserve the established initializer style; deprecated

Read-only target preflight captured the accepted v2.114 API/Web and exact

The installed target fills the two previously checked B2 minute records and
preserves their actual verification timestamp. It does not establish live

notification delivery or archive recovery. B2 rotation remains a separate
operational decision; warning data must not imply that it has already happened.
