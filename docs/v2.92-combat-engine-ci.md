The required `Container Smoke` gate now runs the existing `map_stats_smoke`
fixture in the shared pinned engine runner. Its four results are mandatory:
`MAP_STATS_SMOKE`, `KILL_HEAL_SMOKE`, `KILL_AMMO_SMOKE` and `KILL_STREAK_SMOKE`.
The suite grows to 21 cases / 35 markers and ten hash-bound compiled binaries.

publication, addon publication or production rollout apply. Reverting the CI
change restores the v2.91 gate without player-data recovery.

## Coverage and isolation

The unchanged fixture uses six synthetic clients and native damage/death events
inside ReHLDS/ReGameDLL. Designated fixture clients bypass ordinary bot exclusion;
the exclusion itself is exercised separately. Checks cover:

- map kills/deaths, private `/stats` and bounded `/top`, ordering, cooldowns,
  excluded participants, disconnect and slot resets;
- HP rewards, fractional HP, the 100 HP cap, external surplus, disabled values,
  posthumous kills and excluded events;
- reserve refill for all nine loadouts including shared ammo, preserving clips,
  active weapon, inventory, surplus and unowned ammo pools;
- private RU/EN announcements at streaks 3/5/10, no duplicate announcements,
  current/best counters, death and connection resets, exclusions and saturation.

Every marker must occur exactly once with `failures=0`. Runner regression tests
remove, fail and duplicate each combat marker while leaving the other three
successful. The shared runtime still rejects assertions, native errors, missing
localization, nonempty AMXX error logs, timeouts and incomplete evidence.
The intentional engine assertion and missing-map-provider negative runs remain
mandatory, with their exact failures and container cleanup independently checked.

Image and archive pins are unchanged. The engine remains unprivileged in a
disposable container with no network or published ports, read-only inputs,
45-second process and 600-second suite limits. Only owned containers are removed.
Diagnostics are retained for seven days, including failed hosted runs.
The legacy standalone combat script is not used by the required gate.

compile `amxx-weapon-selection.ps1 -MapStatsFixture` into the same compiler cache
before packaging. Python 3.12 or newer and Docker are required. Each runner
output directory must be new.

- Intentional assertion rejected in 40.736 seconds; missing provider

- All owned containers were removed, fixture identities matched in all three

Full hosted CI passed restore with NuGet audit, formatting, build, tests, the
vulnerable-package report, container checks and browser checks. The unchanged
.NET suite was not repeated locally. No C# changes; InspectCode is not applicable.
