# v2.61 - Согласование backup baseline и неисполненного слота

Статус на 2026-10-11: локальное исправление и focused проверки; публикация,
установка и production reconciliation пока не выполнены.

## Причина и граница

Первый weekly слот 2026-10-11 стартовал в 04:00 МСК и завершился ошибкой
через пять секунд. Backup baseline сохранил хеши прежнего addon; три записи
plugin/dictionary/receipt не совпали с принятым addon 0.23.0. Все четыре live
payload-файла и manifest receipt соответствовали принятому v2.57. Guard
отклонил Host initialization до игрового ledger claim и stop/capture/start.

На игре отсутствовали pending, каталог слота и архив; игра и агент работали
с прежними InvocationID. Независимый A2S отвечал. На control-plane сохранился
`started`, прежняя проверенная ручная копия от 2026-10-08 и блокировка следующих
попыток. Мониторинг корректно показывал `PlayerBackupInterventionRequired`;
семь правил, heartbeat, Grafana dashboard и datasource были исправны.

R3: host backup scripts, журнал одной доказанно неисполненной попытки и reader
мониторинга. Игровые данные, addon, API/Web/PostgreSQL, расписание, окно,
ограничение пустого сервера, backup retention и предупреждения не меняются.
Container images, release tags и перезапуск игры не нужны.

## Изменения

- Hash-bound helper принимает только reviewed manifest и прежний baseline hash,
  сверяет live payload/receipt и отказывает при любом постороннем drift.
  Прежний baseline сохраняется до атомарной замены. Этот шаг включен в
  обязательную приемку последующих addon upgrades и rollback.
- Read-only status может доказать отсутствие игрового capture после окна.
  Сверка control-plane разрешена только для нетронутого `started`, без архива,
  по свежему proof и неизменным хешам pending/last-success.
- Исходные записи и proof сохраняются; terminal state `reconciled-no-capture`
  не обновляет копию, не повторяет side effects и не маскирует service failure.
  Monitor/Grafana отображают отдельный код 8. Прерывание сохраняет блокировку.

Локальные проверки: 13 maintenance cases, 19 weekly regression cases,
20 monitor cases, shell host guard и restricted dispatcher прошли.
Изолированный monitoring stack прошел: новый код, прежний capture timestamp,
21 backup и 25 leaderboard policy cases, invalid/recovery и Grafana mapping.

ровно три ожидаемые замены и отсутствие capture; записей сервера оно не меняло.
CI routing smoke прошел. Итоговые CI и target evidence пока pending.

required CI остается полным из-за инфраструктурной границы.

runtime identities; установить reviewed совместимые scripts/monitor/dashboard;
