# v2.69 - Public keyboard navigation and text resizing

Implementation complete; publication and production acceptance pending.

The public pages have a localized skip-to-content link, document language and
visible keyboard focus. Long text and navigation reflow when enlarged.
Manual refresh announces its result; automatic refresh announces availability
changes without repeating routine checks or age counters. Connection copying
and navigation without JavaScript remain available.

Web-only R1. No game, API, database, authentication or backup changes.
