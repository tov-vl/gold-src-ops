# v2.40 Player Settings

Status as of 2026-10-05: product PR merged after required CI; weapon addon
0.10.0 installed and independently accepted. No tag or control-plane release.

## Scope

Weapon addon 0.10.0 adds `/settings` and a bilingual settings submenu reached
from the seventh hub item. It privately reports primary/pistol choices for the
next spawn and the effective RU/EN language, then opens weapon/language actions
with a Back action to the hub. The hub still fits seven items; existing direct
commands, first-spawn timing, map delegation and inventory rules stay unchanged.
Spectators can inspect settings/change language but cannot select weapons.

"Saved" requires a valid matching record in the existing preferences nVault,
with no pending or blocked write. Fresh defaults, unknown/shared/duplicate
identities, mismatched/corrupt records and unavailable storage are described as
connection-only. Inspection does not create defaults or rewrite a matching
record. Existing explicit selections and late-auth handling still own writes.
No reset action, new vault/schema, identity fallback, rank/statistics change,
global leaderboard, telemetry or API/Web work belongs to this slice.
