# v2.82 - Цветная подсказка при входе

Состояние на 2026-10-19: исправление и package addon 0.29.0 готовы локально.
Remote CI, merge и production-установка еще не выполнялись. Класс риска R1:
меняется только оформление существующей приватной подсказки.

## Изменение

На снимке после клиентской проверки v2.81 первая подсказка с `/menu`, `/guns`
и `/help` оставалась одноцветной, хотя следующая строка ранга уже использовала
цветовые акценты. Причина - вызов `client_print` в `ShowWelcome`.

Подсказка переведена на существующий `PlayerChat`: зеленые префикс и команды,
обычный цвет пояснений. Общий форматтер соблюдает лимит 190 байт и сохраняет
переведенный текст при недостатке места для цветовых кодов. Для приветствия
EN занимает 86 байт с цветами, RU - 107; запас достаточен для обеих локализаций.

Тексты и словарь не менялись. Показ один раз за подключение, проверки живого
игрока, отмена таймера, поведение активного меню и последующая строка ранга
сохранены. Код vault, схемы данных, выдача оружия, поиск и API/Web не меняются.
Версия plugin и диагностических статусов повышена с 0.28.0 до 0.29.0.

## Локальная проверка

- Продукт и три существующих fixtures (player menu, spawn loadout, persistent
  stats) скомпилированы AMXX 1.10.0.5481 / ReAPI 5.24.0.300 без предупреждений.
- Dictionary smoke проверил 74 ключа в RU/EN. Package smoke подтвердил schema 2,
  четыре payload, SHA-256 и отказ перезаписи результата.
- Три сценария изолированного ReHLDS 3.15.0.896 / ReGameDLL 5.30.0.814 прошли
  за 31.514 секунды без assertion failures и AMXX errors. Контейнер
  работал без сети и опубликованных портов, входные каталоги были read-only.
- Проверки меню/справки подтвердили общий цветовой форматтер, RU/EN, лимит чата,
  пять строк справки и однократность приветствия. Spawn/loadout проверил
  первое появление, отмену и повтор таймера, bot/spectator/dead guards,
  сохранение активного меню и девять наборов оружия.
- Persistent stats/rank проверил приватные приветствие и ранг, независимость
  cooldown, pending identity и прежнее поведение настоящего nVault.

Новые fixtures для этой косметической правки не добавлялись. Полные .NET/browser,
остальные движковые сценарии и installer/recovery rehearsals не повторялись.
Изолированный движок не подтверждает внешний вид сообщения в реальном клиенте.
