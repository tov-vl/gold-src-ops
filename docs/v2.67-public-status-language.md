# v2.67 - Единый язык публичного сайта

## Граница

R1, только Web. Главная страница, общая публичная навигация и подвал
продолжают RU/EN контракт v2.66. API, BFF, Operator content, игра, addon,
сохранения, backup и мониторинг не меняются.

## Поведение

- Русский по умолчанию; ?lang=en выбирает English. Регистр не важен,
  неизвестный язык дает русский, повторный параметр использует первое значение.
- Логотип, главная навигация, ссылка на общий статус и инструкция соединяют
  /, /play и /leaderboard с сохранением языка.
- Переключение языка на главной сохраняет выбранную историю 24h или 7d;
  переключение периода сохраняет язык. Неизвестный период дает 24h.
  Посторонние параметры не переносятся в ссылки.
- Переведены штатные состояния, ошибки, отсутствие данных, подписи графика,
  пояснение границ A2S и сообщения clipboard. UTC и числовые значения
  сохраняют invariant формат. Имя сервера, карта и команда не переводятся.
- Общая оболочка явно задает язык содержимого. Operator content и его
  оболочка остаются английскими. Аутентификация не меняется.
- Все переходы работают без JavaScript. Cookies, browser storage и глобальная
  культура запроса не добавляются. Язык игры остается независимым.
- Ссылка "Как начать" явно ведет на секцию /play, сохраняя язык при
  установленном базовом адресе документа.

## Проверка и выпуск

Проверяются SSR, изоляция публичных проекций, ошибки, 24h/7d, RU/EN,
неизвестные значения, no-JavaScript, clipboard и ширины 1440/390/320px.
Выпуск требует полного Quality Gate, required CI, Web container smoke,
проверенных immutable digest, Web-only rollout и публичной приемки.
Rollback возвращает предыдущий Web digest; повторный игровой сеанс не нужен.

См. [readiness](v2.67-readiness.md), [release notes](release-notes-v2.67.md).
Визуальная приемка v2.63, игра вдвоем и первый успешный weekly timer
остаются независимыми.
