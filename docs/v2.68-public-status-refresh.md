# v2.68 - Актуальный статус на открытой главной

Принято 2026-10-12: stable v2.68.0 из принятого v2.68.0-rc.1.

## Граница

R1, только Web. Главная использует существующие публичные проекции через
server-side HTTP. API, БД, авторизация, игра, addon, backup и мониторинг
не меняются. Визуальная приемка v2.63 остается независимой.

## Поведение

- Обновление раз в 60 секунд в видимой вкладке и ссылка "Обновить".
  Без JavaScript ссылка выполняет обычную загрузку страницы.
- Один GET к нормализованному /?range=24h или /?range=7d с RU/EN в URL.
  Cookies не отправляются, redirects запрещены, браузер не обращается к API.
- Timeout 8 секунд, максимум 128 KiB, не более одного активного запроса,
  минимум 5 секунд между попытками. Следующая автоматическая попытка через
  минуту, без немедленных повторов. Скрытие вкладки отменяет запрос;
  pagehide/pageshow останавливают и восстанавливают один таймер.
- Перед изменением DOM проверяются язык, период, структура, размер, тип
  содержимого, допустимые элементы/атрибуты и ссылки подключения.
- Fleet и публичный сервер имеют независимый возраст последнего наблюдения.
  Сервер вычисляет начальный возраст; браузер добавляет монотонно прошедшее
  время. Через 180 секунд или при ошибке транспорта текущая доступность
  не подтверждена. Карта и онлайн скрываются; счетчики остаются явно
  обозначенным последним снимком. Эта граница действует и в исходном SSR.
- Fleet LastObservedAtUtc - последнее наблюдение агрегата; это не гарантия
  свежести каждого сервера. История показывает прошлые A2S проверки и
  остается видимой при ошибке обновления; это не обещание текущей доступности.
- Частичный отказ join projection сохраняет прежние параметры подключения
  с предупреждением. Успешный ответ об отсутствии конфигурации удаляет их.
  Остальные успешно полученные проекции обновляются независимо.
- Язык, период, документ, прокрутка и существующие элементы подключения
  сохраняются. Если сфокусированный элемент удален, фокус переходит на
  "Обновить". Сообщение clipboard сохраняется до изменения команды.

## Приемка

SSR: свежий, устаревший, отсутствующий timestamp, offline и отказ проекции.
Browser: RU/EN, 24h/7d, ручное и автоматическое обновление, реальные cookies
в исходной сессии без их отправки при refresh, malformed/unsafe/oversized
ответы, частичный отказ, timeout, overlap, hidden и page cache lifecycle,
фокус/scroll/clipboard, no-JavaScript и мобильная верстка.

Production: точный Web digest, независимая runtime проверка, ручной и
настоящий минутный refresh с продвижением наблюдения, RU/EN, оба периода,
1440/390/320px, clipboard и no-JavaScript. Стабильная публикация использует
принятые candidate digests без пересборки и повторного rollout.
