# v2.59 - Обновление рейтинга на открытой странице

## Граница

R1, только Web. Существующий SSR `/leaderboard`, публичный HTTP shape, API,
addon, scoring, сохранения, схема и backup schedule остаются прежними.
JavaScript выполняет anonymous same-origin GET этой же публичной страницы,
передавая no-store и omit credentials. API/RCON вызываются только сервером.
В документе заменяется лишь блок результатов; навигация и фокус сохраняются.
Без JavaScript ссылка "Обновить" выполняет обычную загрузку SSR.

## Обновление и свежесть

- Автоматический проход раз в 60 секунд только в видимой вкладке.
- Ручной проход доступен сразу; между началами запросов минимум пять секунд.
- Единственный запрос за раз, timeout восемь секунд, HTML до 128 KiB.
  Ошибка не запускает немедленный retry; следующий автоматический проход
  следует обычному расписанию. Redirect, неверный content type или блок
  результатов отклоняются. Сырые ошибки не отображаются и не сохраняются.
- Возраст вычислен сервером и увеличивается монотонным временем браузера.
  Он не зависит от календарных часов клиента. Fresh не сохраняется после
  трех минут; сетевой сбой сразу переводит прежние строки в stale. После
  суток прежние строки убираются. Успешный empty отличается от unavailable;
  unavailable от сервера сразу заменяет старую таблицу.
- Скрытие вкладки и уход со страницы отменяют незавершенный запрос.
  Возврат сверяет возраст и при истекшем интервале обновляет данные.
  Browser back/forward cache восстанавливает один timer.

Частота обновления страницы не ускоряет минутный источник API и не означает
изменение счета в момент последнего боя. Пилот не обещает realtime или SLO.
Никаких токенов, идентификаторов игроков, локального browser storage или
защищенных browser-to-API запросов не добавляется.

## Проверка и recovery

SSR tests, браузерные сценарии manual/auto/failure/recovery/hidden/resume,
timeout/overlap/expiry, ограничений ответа и fallback без JavaScript; полный
локальный Quality Gate и required CI. После digest-pinned Web-only rollout:
health, manual и реальный минутный refresh, desktop/mobile, отсутствие
browser-to-API запросов, сохраненные остальные контейнеры и volumes.

Rollback восстанавливает только прежний Web digest с неизменным env/config
и остальными сервисами. Миграции и game-host transition не требуются.
Первый weekly backup, клиентская v2.55 и игра вдвоем остаются независимыми.
См. [readiness](v2.59-readiness.md).
