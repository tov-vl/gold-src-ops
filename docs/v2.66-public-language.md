# v2.66 - Язык публичных страниц

Принято 2026-10-11: stable `v2.66.0` из принятого `v2.66.0-rc.1`.

## Граница

R1, Web-only: `/play` и `/leaderboard` получают RU/EN переключатель,
переводы инструкций, команд, рангов, состояний, пустых результатов,
ошибок и сообщений refresh/copy. API, scoring, addon, игра, сохранения,
backup, мониторинг и аутентификация не меняются.

## Контракт

- Русский язык остается по умолчанию. `?lang=en` включает English;
  сравнение без учета регистра, неизвестное значение дает русский.
  При повторном параметре используется первое значение согласно Blazor binding.
- Язык сохраняется в ссылках между двумя страницами, их основной навигации,
  ручном refresh и автоматических запросах. Ссылку можно сохранить или передать.
  Это выбор конкретного URL, не постоянная настройка аккаунта или браузера.
  Переход на URL без параметра снова выбирает русский. Язык игры независим.
- Переключатель работает обычными GET-ссылками, включая режим без JavaScript.
  Cookies, localStorage, sessionStorage и общий request culture не добавляются.
- Общий каталог `.resx` принадлежит Web. Razor кодирует строки и данные;
  скрипты получают только статические переводы через HTML data attributes.
  Ник, карта, адрес, команда подключения и значения статистики не переводятся.
- Refresh сохраняет существующие ограничения: один запрос, 60 секунд,
  timeout 8 секунд, HTML до 128 KiB, omit credentials, no-store и запрет redirect.
  Ответ с другим языком отклоняется до замены данных. Возраст продолжает
  вычисляться монотонно, машинные атрибуты и UTC остаются invariant.
- Главная страница статуса и Operator UI не локализуются этим этапом.

## Проверка и recovery

Focused SSR проверяет выбор и fallback, публичные API-проекции, пустые данные,
ошибки и отсутствие новых cookies. Browser cases покрывают навигацию RU/EN,
copy, 1440/390/320px, no-JavaScript, manual/automatic refresh, отказ transport,
неверный язык ответа, recovery и отсутствие credentials в refresh.

Полный local Quality Gate, 43 browser cases и required CI прошли.
На принятом Web digest проверены health, независимая identity, RU/EN страницы,
реальный минутный refresh, mobile/no-JavaScript и сохранение шести остальных
сервисов. Rollback возвращает только предыдущий Web digest. Старый открытый
English документ после rollback отклонит русский refresh до reload.

Визуальная приемка v2.63, первое успешное weekly timer выполнение и игра вдвоем
остаются независимыми. См. [readiness](v2.66-readiness.md) и
[release notes](release-notes-v2.66.md).
