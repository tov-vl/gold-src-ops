# v2.37 Bilingual Player Menu

Status as of 2026-10-04: addon 0.8.0 and its RU/EN dictionary are installed
and accepted on the pilot. Focused local checks, required product CI and
independent external/host checks passed. Real-client Cyrillic rendering
remains an optional unverified MVP observation.

## Behavior

The existing weapon addon 0.8.0 exposes `/menu`, `say_team /menu` and console
`menu`. Seven entries open weapons, saved/session stats, saved rank, current-map
leaders, map voting, time left and language selection. Stats/rank/top reuse
their existing independent cooldowns and private output; map actions delegate
fixed `/maps` and `/timeleft` commands to the unchanged map addon. Weapons
remain playing-team-only and apply at the next spawn, not immediately.
Spectators may open the hub for read-only stats. Bots/HLTV, stale menu handles,
invalid items, disabled addon and cancellation cannot trigger hub actions.

Native AMXX `[ru]`/`[en]` translations cover the hub, weapon menus, confirmation,
welcome, stats, rank names/progress/promotion and map-leader messages. An empty
client `lang` uses Russian; supported RU/EN is respected; unsupported languages
use English. Manual selection overrides only this connection and addon.
It does not modify client preferences, global AMXX language, player storage
or other plugins. The language picker presents both language names.

Manual `/menu` suppresses the pending automatic first-spawn weapon menu;
otherwise the existing first-spawn welcome/menu remains once-only. Map-addon
menu/vote/time-left messages remain English in this slice. Machine status,
weapon names, thresholds, scoring, saved identity/schema and cooldowns are
unchanged. No language/rank persistence, new module, XP, reward or API is added.

## Delivery Boundary

The menu is presentation-only, but extending installation/recovery ownership
to a dictionary selects the higher R3 tool boundary. Rehearse only that changed
file transition; do not repeat accepted telemetry/boot or storage lifecycles.
Schema-2 receipts bind the dictionary; schema-1 legacy weapon/map receipts are
still valid. Use the updated installer for reverse upgrade to accepted 0.7.0:
restore its binary/receipt and remove only our dictionary. Preserve config,
loader state, exact baseline, agent invocation and closed vault/journal.

Before rollout, freshly verify zero players/bots, the exact accepted predecessor,
safe root-owned `data/lang`, guards and rollback inputs. Then use one short
stopped-game transition and independent A2S/addon/host check. Do not change
directory ownership broadly or alter boot policy. Stop on unexplained drift;
an uncertain mutation is not permission for an automatic retry.

No full local .NET suite, mandatory player session, soak, reboot, Auth0 prompt,
agent restart, queue rewrite, API/Web deployment or image/tag publication is
required for this slice. Real-client Cyrillic font/rendering, comfort and
multiplayer balance remain optional unverified MVP observations, not synthetic
fixture claims. Local checks alone do not establish host acceptance.
