# v2.48 Player Help

Status as of 2026-10-08: addon 0.18.0 implemented, packaged and verified locally.
PR CI, merge and installation remain separate gates. The accepted game-host
addon remains 0.17.0.

## Scope

`/help` in public/team chat and `help` in the console privately print six short
RU/EN lines: menu/settings, next-spawn weapon selection, statistics/ranks/map
leaders, map commands, and independent language/weapon and HUD persistence
status. The existing welcome gains a `/help` hint and remains once-only. Help
does not open or replace menus, cancel the pending welcome, apply weapons,
flush pending preferences, write nVault records or alter ranks/statistics.

Help uses the already effective player language without triggering preference
reconciliation. A five-second per-connection cooldown bounds repeated calls.
Invalid/disconnected, bot/HLTV and disabled-addon callers get no output. Dead
players and spectators can read help. Connection/slot reset clears the cooldown.
Persistence wording reuses the settings checks: only exact matching records are
described as saved; unavailable, pending or mismatching records stay session-only.

The seven-item hub, first-spawn timing, HUD positions/timing, loadout, combat
rewards, map addon and control-plane contracts remain unchanged. No new storage
schema or migration is needed. The two-player scenario remains deferred
indefinitely and is not required for this help boundary.
