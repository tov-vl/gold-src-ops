## Boundary

The private RU/EN `/profile` adds a "Next spawn" section with the selected
primary weapon and pistol, followed by the existing saved/session-only wording.
It describes the selection for the next spawn, including a selection made while
alive; opening the profile does not equip or replace a weapon.

The saved claim requires a validated record loaded during the connection, or
the existing successful native write/readback, matching the current language
override and both weapon choices. A small in-memory snapshot records that
confirmation. Absent, dirty, blocked, unavailable, unready or mismatched state
uses the session-only wording. Slot reset clears the confirmation.

Viewing the profile reads loaded memory only. It does not load identity, read
or write nVault, flush pending preferences or change inventory. Existing stats,
standing, streak, aliases, five-second cooldown and exclusions remain. The
1536-cell MOTD buffer, preference schema, HUD storage, gameplay settings,
map addon, event agent and application services are preserved.
