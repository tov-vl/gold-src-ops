## Scope

Reuse the existing weapon addon rather than install another plugin. The first
eligible living human T/CT spawn schedules a one-second welcome callback. It
prints a short `/guns`, `/maps`, `/timeleft` hint and opens the primary weapon
menu only when no menu is already active. The existing primary/pistol flow and
next-spawn inventory application remain unchanged; opening or selecting a menu
does not replace weapons or refill ammunition during the current life.

Further respawns do not repeat the welcome. Manual `/guns` consumes the pending
automatic display and cancels its timer. Disconnect and client-slot reuse
cancel/reset welcome state. Disabled, dead, spectator, bot and HLTV clients do
not receive it. A callback that finds a dead/ineligible client leaves the next
eligible spawn available; a busy menu gets only the hint, not a forced menu.

The state is local to the current plugin/map lifetime, like the existing weapon
choices: reconnect or map/plugin reload can show the welcome again. It is not
persisted as player identity or a cross-map preference. The hint assumes the
separately accepted map-menu addon is enabled on the pilot. No ranks, database,
round rules, spawns, vote thresholds, telemetry or boot policy change belongs
to this slice.

The callback uses the pinned native timer/menu APIs; see
[set_task](https://www.amxmodx.org/api/amxmodx/set_task) and
[get_user_menu](https://www.amxmodx.org/api/amxmodx/get_user_menu).
