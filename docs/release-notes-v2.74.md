# v2.74 - Player rank guide

Pending release acceptance.

`/play` shows all five ranks and their saved enemy-kill thresholds. The public
leaderboard links to the guide and explains why rank differs from top-10
position. RU/EN, keyboard navigation, mobile layouts and no-JavaScript browsing
are supported. Existing rank names are reused and the Russian introduction no
longer lists English rank names.

This is Web-only content and presentation: gameplay, player saves, API contracts
and monitoring policies are unchanged. See [readiness](v2.74-readiness.md).
