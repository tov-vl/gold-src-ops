# v2.74 - Player rank guide

R1, Web only. `/play#ranks` presents a semantic two-column table with the five
addon rank thresholds: 0, 25, 100, 250 and 500 saved enemy kills. Existing localized
rank names are reused. The guide distinguishes cumulative rank progress from
relative top-10 position and explains that deaths do not lower rank, Legend is
the maximum rank and ranks confer no combat advantages.

`/leaderboard` links to the focusable guide in the selected RU/EN language.
Static server-rendered content works with JavaScript disabled and when public
API data are unavailable. Refresh continues to replace only its existing live
data boundary; the guide adds no API request or browser storage.

The browser contract compares rendered thresholds with `RANK_KILLS` in the
versioned addon source, preventing unnoticed drift when gameplay thresholds
change. It also covers localized names, keyboard fragment focus, missing data,
no-JavaScript navigation and 200% text at 320/390/1440px. No addon code, rank
calculation, API contract, saved-player data or gameplay behavior changes.

Deploy only the verified Web digest and retain the previous Web digest for
rollback. Preserve the six other services, mounts and monitoring configuration,
including v2.73 rules. Game visual acceptance is independent. See
[readiness](v2.74-readiness.md) and [release notes](release-notes-v2.74.md).
