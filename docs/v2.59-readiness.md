## Anomalies And Limits

The first browser timeout test tried an ordinary click on an aria-disabled
control. Playwright correctly refused; explicit repeated-event dispatch proved
the overlap guard. The first full local test phase failed 41 PostgreSQL cases
because Docker was stopped; launching the existing daemon and repeating only
the failed phase resolved them. These were known local tooling failures.

The first read-only rollout plan rejected mount order. A second independent
read confirmed all complete mount objects equal, with unchanged configuration,
container IDs/images and restart counts; Docker inspect had reordered arrays.
The operator verifier now sorts complete objects without removing any field.
Only the read-only plan was repeated; no runtime effect or uncertain retry
preceded the single successful execution. Rollback was not required.

The minute page refresh reads the existing minute API cache; it does not force
a game read or promise immediate scores. Without JavaScript, age/state remain
those of the SSR response until normal reload. An older open page after Web
rollback may fail refresh validation and show stale until reload; no state is
written to browser storage. In-memory BFF sessions retain the existing restart
boundary; authenticated continuity is not claimed.

No interactive login, Steam launch, gameplay-client session, backup execution,
restore, migration or personal delivery was performed. First weekly backup on
2026-10-11 at 04:00 MSK, empty server only; v2.55 client acceptance and two-player
play remain deferred independent tasks.
