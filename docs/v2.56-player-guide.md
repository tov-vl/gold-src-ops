# v2.56 - Страница для нового игрока

Принято 2026-10-09: stable `v2.56.0` опубликован, проверенный Web digest
установлен. Local Quality Gate, все 24 браузерных boundary tests, required CI,
независимые published-image smoke и production приемка прошли. Граница - R1,
только Web; остальные шесть сервисов сохранили контейнеры и время запуска.
Откат не потребовался.

## Поведение

Анонимная русская страница `/play` объясняет текущий командный пилот CS 1.6
с быстрым возрождением, выбором оружия и сохраненными рангами. Три шага
проводят игрока от подключения и выбора стороны к `/guns` и `/profile`.
Справочник содержит `/menu`, `/guns`, `/profile`, `/settings`, `/maps` и `/help`.
Звания не обещают боевых преимуществ. Сохранение связано с подтвержденной
Steam-идентичностью; недоступное сохранение не блокирует игру.

Подключение находится рядом с картой, числом игроков и временем последней
проверки. Steam-ссылка и команда `connect` используют только опубликованные
host/port из существующей проекции. Кнопка копирования имеет русское
подтверждение и ручной fallback. Основная навигация и ссылка с главной
страницы ведут на `/play`; scoped CSS применяет стили к дочерним `NavLink`.

Страница читает `/api/public/server` через существующий серверный
`PublicStatusClient`. Браузер не запрашивает API, не получает bearer tokens
и не выполняет защищенные действия. Static SSR не добавляет polling,
интерактивный серверный circuit или новый источник игровых данных.

## Неуспех и достоверность

`offline`, `unknown` и неожиданный state не показывают старую карту и
население как текущие. Адрес остается доступным для попытки подключения,
но текст явно сообщает, что доступность не подтверждена. Возраст снимка
остается видимым; существующий API владеет классификацией stale как unknown.
При отсутствии конфигурации, HTTP-ошибке или недоступном API инструкции
остаются на странице, а выдуманного адреса и кнопки подключения нет.
Динамические имя и карта проходят обычное HTML encoding Razor.

Описание режима является редакционным текстом одного текущего пилота.
При изменении профиля или игровых команд его нужно обновить вместе с
пилотом. Страница не выводит персональный рейтинг, private host/RCON,
сырые ответы провайдера или операторскую информацию.

## Проверки и ограничения

SSR проверяет анонимный доступ, единственный публичный запрос, точные ссылки,
недоступные состояния, HTTP 404/503 и HTML encoding. Chromium проверяет
переход с главной страницы, активную навигацию, копирование и отказ clipboard,
отсутствие горизонтального overflow при ширине 1440, 1024, 390 и 320,
мобильные offline/unknown/unavailable, отсутствие токенов и browser storage.

Steam handler и реальный игровой клиент этими проверками не запускаются.
Клиентская приемка v2.55, игра вдвоем, первый weekly backup и личные
уведомления остаются отдельными задачами. Они не являются gate этой страницы.
