# v2.50 - Еженедельный backup игровых данных

Статус на 2026-10-08: локальная реализация и проверка завершены; установка не выполнена.
Режим выбран владельцем: воскресенье, 04:00 МСК, только при пустом сервере.
См. [процедуру и границы](game-player-data-schedule.md).

## Scope

R3: автоматизация закрытого capture и существующего Archive/readback.
Две проверки A2S, прежний runtime, общий transition lock, один stop/start,
недогоняющий weekly timer и постоянный журнал неопределенных операций.
Контроль свежести использует время capture и порог восемь суток; занятый
сервер не обновляет дату успешной копии. Хранение ограничено 52 слотами;
автоматического удаления или production restore нет.

Addon 0.18.0, форматы vault, API/Web/PostgreSQL и игровой агент не меняются.
Игра вдвоем остается отложенной на неопределенный срок.

## Локальная проверка

- 19 Python-сценариев: окно Europe/Moscow, занятая игра и поздний вход,
  однократный stop/start, failure matrix, lost reply, uncertain upload,
  блокировка следующих недель, hash/slot mismatch, свежесть по capture time,
  начальный ручной baseline, local A2S endpoint/port, private paths, symlink,
  locks и лимит хранения.
- Bash fixture проверяет host guard и SSH dispatcher с заменой системных команд, включая
  отказ при неверном baseline, queue/spool, PID/process probe, лишних
  аргументах, traversal и shell injection.
- ShellCheck, bash syntax, actionlint и SSH client template parse прошли.
- 14 существующих bundle-тестов и capture guard regression прошли.
- Полный локальный Quality Gate прошел: restore, format, build без warnings/errors,
  875 успешных тестов, 22 штатно пропущенных browser tests и dependency audit без
  известных уязвимых пакетов. Отдельный браузерный прогон не запускался.
- CI fast-path smoke подтвердил полный маршрут для этой ревизии.
- Новые проверки включены в полный CI. Shared ops/workflow оставляют полный
  маршрут; addon-only исключение не расширялось.

## Прочитанное внешнее состояние

Read-only аудит control-plane не обнаружил client SSH config или public identity
files в проверенных root/operator SSH-каталогах; настроенного канала для
автоматического backup этим аудитом не найдено. Private keys не читались.
Наличие identity без public companion или вне этих каталогов не исключается.

Штатный systemd на control-plane принял
`Sun *-*-* 04:00:00 Europe/Moscow`: ближайшие моменты -
2026-10-11 и 2026-10-18 в 01:00 UTC. Это проверка выражения календаря,
не доказательство установки timer.

## Оставшаяся приемка

Нужны публикация точной ревизии и required CI, новый ограниченный машинный
SSH-канал, установка и проверка timer. Новые account/key/sudo и возможный
SSH ingress не входят в ранее завершенный bundle v2.49; для них подготовлен
единый план в runbook. До разрешения этой границы ничего из этого не создавалось.

После установки первый фактический воскресный cycle остается отдельным
наблюдаемым результатом. При занятости сервера ожидается skipped-busy;
при неизвестном результате следующие попытки блокируются. Отдельный
engine rehearsal для каждой будущей копии и гарантированный RPO/RTO не заявлены.
