# v2.41 Player HUD

Status as of 2026-10-05: product PR merged after required CI; weapon addon
0.11.0 installed and independently accepted. No tag or control-plane release.

## Scope

Weapon addon 0.11.0 adds a private two-line native AMXX HUD: connection/map
kills and deaths, then the existing saved rank and kills to its next tier.
The highest tier and unavailable saved statistics have explicit RU/EN text.
Language follows the accepted player preference. One one-second timer reads
in-memory counters only; rendering does not load or write nVault records.

HUD is enabled by default for alive human players on a playing team. Native
menu state takes priority, including VGUI menus; an empty cleared-menu state
does not suppress the HUD. Death, spectator/bot state, global disable and the
player toggle clear the synchronized message. `/settings` gains a private
On/Off item and keeps explicit Back. The toggle is not saved: reconnect, map
reload or plugin restart restores the default. Weapon/language preferences,
statistics schema, scoring, rank thresholds, loadouts and map voting are
unchanged. No external plugin, new vault, API, telemetry or leaderboard.

One required product CI and one stopped-game addon installation suffice.
