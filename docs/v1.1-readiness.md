## Compatibility Review

- The v1 REST endpoints and `Reader`/`Operator` policy matrix are unchanged.
- No EF Core migration is added by v1.1. Existing migrations still run as a
  separate deployment action before the application rollout.
- Polling and snapshot retention remain singleton responsibilities. Command
  dispatch can still use multiple workers because PostgreSQL owns claims and
  per-server serialization.
- The container and deployment guide are additive. Existing Development startup
  and demo workflows remain available.
- The direct Prometheus endpoint remains authenticated and backward compatible.
  Architecture Decision 12 records the prerelease risk and future OTLP trigger.

## Local Release Verification

The candidate gate ran on 2026-08-22 with .NET SDK `10.0.400`, Docker Engine
`29.7.2`, and PostgreSQL `16-alpine` in the isolated smoke flow:

```powershell
dotnet restore GoldSrcOps.sln -p:AuditPipeline=true
dotnet format GoldSrcOps.sln --verify-no-changes --verbosity minimal --no-restore
dotnet build GoldSrcOps.sln --configuration Release --no-restore
dotnet test GoldSrcOps.sln --configuration Release --no-build --no-restore
dotnet list GoldSrcOps.sln package --vulnerable --include-transitive --no-restore
pwsh -NoProfile -File .\tools\smoke\container.ps1
```

Results:

- restore with NuGet Audit succeeded;
- formatting verification produced no changes;
- Release build completed with zero warnings and zero errors;
- all `141/141` tests passed;
- no vulnerable direct or transitive NuGet package was reported;
- the production image passed runtime-content and non-root checks;
- missing Production configuration failed fast as expected;
- migrations were applied separately to a clean PostgreSQL database;
- the hardened API container returned healthy liveness and readiness results;
- the smoke script completed its finally-based resource cleanup.

The package review also confirmed that `1.18.0-beta.1` is the current direct
Prometheus exporter release. Its changes fix concurrent scrape behavior,
timeout status, content negotiation, and numeric serialization. The stable
`1.18.0` breaking change concerns OTLP request limits; GoldSrcOps does not use
the OTLP exporter.

## Accepted Boundaries

- The repository verifies but does not publish the container image. Registry
  authentication, image provenance/signing, digest retention, and promotion
  belong to a future release pipeline.
- Target-environment TLS, identity-provider metadata, database TLS, secret
  injection, probe routing, and backup restoration require deployment evidence;
  the repository smoke test cannot prove those integrations.
- The direct Prometheus exporter remains prerelease. `/metrics` stays behind
  the `Reader` policy and a private deployment boundary.
- Provider-specific production manifests and multiple active polling workers
  remain outside v1.1.
- Alert delivery and an outbox remain the first planned v2 capability.
