## Anomalies and limits

Production baseline reproduced 108px horizontal overflow on the Russian home
page and 119px on the Russian player guide at 320px with double text. Both
are resolved under the same acceptance check.

The first local full run caught unsupported query values reflected by the
new skip link. After normalization and consistent duplicate-language handling,
eight focused integration cases, all 308 Web tests and all 53 browser cases
passed. Unchanged Unit/receiver suites were not repeated. Initial indentation
and an overstrict clipping assertion were corrected. The read-only production
browser helper initially stopped because the bundled runtime does not export
the test-runner assertion helper. It was corrected to use bounded polling
assertions and rerun without another rollout. No application failure or
rollback occurred.

Doubled root text and a 720 CSS-pixel viewport are explicit text/layout checks,
not full browser-zoom equivalence. Live-region semantics and mutation counts
do not prove spoken output in NVDA/JAWS/VoiceOver. No screen-reader listening
session or complete WCAG conformance is claimed.

No game restart, backup, restore, migration or player session was performed.
Game visual acceptance v2.63 and the first successful weekly timer cycle remain
independent; two-player play remains deferred. No new interactive OIDC check
was run; existing BFF sessions retain the usual Web restart boundary.
