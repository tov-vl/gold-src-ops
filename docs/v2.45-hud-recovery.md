Status as of 2026-10-07: addon 0.15.0 merged, installed once and independently
verified on the active game server. Human-client visual acceptance is pending.

## Observed Problem

The owner completed the non-combat checks on 2026-10-06 and reported two HUD
issues: text was too small at 2560x1600 in OpenGL widescreen windowed mode,
and closing `/menu` hid the HUD until reconnect. Toggling HUD off/on did not
recover it. The other non-combat checks were reported successful. Combat
rewards, streak milestones and multiplayer balance remain untested by humans.

## Change

AMXX's `menuselect` handler clears the active menu identifiers but retains
the key mask. The old HUD condition treated any remaining keys as an open
menu. The HUD now checks the active menu identifier; key residue alone does
not suppress it. Active addon, legacy and VGUI menu identifiers still take
priority. Recovery occurs on the next one-second HUD tick.

The renderer changes from small synchronized HUD text to Director HUD for
larger client text. Statistics/streak and rank are sent as two bounded private
messages at separate vertical positions. Each message expires after one second
without fades; opening a menu, disabling HUD, dying or becoming a spectator
stops refresh. A previously sent frame may remain for up to one second.
Director messages have no individually addressable channel, so the addon does
not attempt to clear other plugins' messages.

Language, wording, saved preferences/statistics, ranks, scoring, rewards and
weapons keep their existing contracts. The HUD toggle remains connection-only.
Client video settings and client files are not modified.

the native menu-selection handler, so this is state/dispatch coverage rather
than a real client's keypress. It covers repeated hub exit, off/on plus exit,
weapon selection, Back to the hub, and an external legacy menu in both languages.

The corrected menu/HUD engine fixture passed with zero failures. Restoring only
the old predicate in an isolated source copy produced 17 assertions, including
every stale-key recovery case. Payload checks cover both translations, bounded
counters, saved/unavailable/highest ranks, two separate message positions and
one-second expiry. Synthetic clients do not prove perceived font size or
positioning at 2560x1600.

Pinned compilation passed for the product and all five gameplay fixtures.
The isolated preferences runtime passed real-nVault save, reconnect/map reload,
HUD/menu, first-spawn and all nine loadout combinations with zero failures and
no AMXX error logs. Dictionary and immutable schema-2 package verification also
passed. Documentation validation checked 123 Markdown files and 598 local links.
The four-path product/docs diff selected `addon-only` locally and in CI.
Full .NET, browser and combat runtime suites were not repeated
because this change affects only HUD rendering and menu-state handling.
