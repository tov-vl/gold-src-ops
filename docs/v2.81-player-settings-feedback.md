# v2.81 - Настройки без лишних сообщений в чат

Состояние на 2026-10-19: addon 0.28.0 принят в main через PR #369; PR CI и
post-merge CI прошли. Подготовлен и локально проверен план установки 0.27.0 ->
0.28.0. Свежая read-only сверка production прошла; установка еще не выполнена.
Класс риска - R2: меняются обработчики выбора сохраняемых настроек, хотя формат
записей и реализация nVault остаются прежними. Изменение ограничено игровым addon.

## Поведение

- `/settings` и пункт 7 в `/menu` открываются без сообщений в чат. В заголовке
  меню видны оружие следующего возрождения, RU/EN и независимые статусы
  сохранения языка/оружия и HUD. Текущее состояние HUD остается в его пункте.
- Каждому клиенту принадлежат свои меню; открытие настроек другим клиентом
  не заменяет персональные значения. Есть четыре пункта, возврат и выход через 0.
  Обработчики отклоняют чужое меню и устаревшее состояние языка/HUD;
  отключение клиента освобождает его меню.
- Изменение языка, основного оружия, пистолета или HUD дает одно короткое
  цветное сообщение только этому игроку. После HUD меню обновляется без
  дополнительных сообщений. Язык подтверждения соответствует выбранному.
- Подтверждение различает проверенное сохранение и действие только на текущее
  подключение. Ошибка readback, pending, LAN или недоступный vault не выдаются
  за успешное сохранение. Ошибка с неопределенным результатом не вызывает retry.
- Повторный выбор уже установленного языка или оружия не дает подтверждения
  и не выполняет повторную запись. Первое явное указание языка сохраняет override,
  даже если до этого клиент использовал тот же язык по умолчанию.
- Просмотр настроек не загружает и не сбрасывает pending-изменения через
  определение языка. Выдача выбранного оружия остается на следующем возрождении.

Схемы preferences/HUD, статистика, рекорды и поиск v1/v2 не меняются.
API, Web, агент, container images, теги и расписание backup не входят в срез.

## Локальные доказательства

- Продукт и пять fixtures скомпилированы AMXX 1.10.0.5481 / ReAPI 5.24.0.300
  без предупреждений. Словарь содержит 74 согласованных ключа RU/EN.
- В изолированном ReHLDS 3.15.0.896 / ReGameDLL 5.30.0.814 прошли 17 сценариев
  за 123,533 секунды. Сеть и опубликованные порты отсутствовали, входы read-only;
  нет assertion failures и AMXX error logs.
- Settings/preferences fixture проверяет тихое открытие, одно приватное цветное
  подтверждение, payload до 190 байт, повторный выбор без записи, независимость
  клиентов, pending и освобождение меню. Проверены RU/EN и все четыре сочетания
  сохранения языка/оружия и HUD через настоящий nVault.
- Инъекции отказа проверяют readback и недоступный vault; прежние сценарии
  сохраняют защиты duplicate/LAN identity и поврежденных записей. Reconnect
  и новый процесс на другой карте восстанавливают оружие, язык и HUD;
  контрольная запись статистики сохраняется.
- Прежние проверки прошли для HUD continuity, пятистрочного `/help`, профиля,
  рейтинга, рекордов, девяти наборов оружия, поиска v1/v2 с общим cooldown
  и 4096 синтетических записей.
- После исправления только пунктуации русского подтверждения HUD повторены
  словарь и четыре затронутых сценария settings/preferences, seed, reload и
  menu/help: 35,447 секунды, все прошли. Исходник продукта не менялся.
- Package smoke подтвердил schema 2, четыре payload и их SHA-256, включенный
  lookup и отказ перезаписи результата. Loader/config побайтно совпадают с
  сохраненным package 0.27.0; меняются только plugin и словарь.

Проверка заголовка перехватывает точный аргумент `menu_setprop` перед передачей
настоящему native, а отображение использует реальные menu handles. Синтетические
клиенты не доказывают визуальное размещение текста. Нужен отдельный короткий
проход реальным клиентом после установки.

Полный .NET/browser suite и прежние installer/recovery fixtures локально не
повторялись: эти границы не меняются. Required CI прошел по
[addon-only маршруту](release-process.md#ci-scope-for-game-addons).
Свежая production-сверка при подготовке плана описана ниже; изменений нет.

Read-only сверка 2026-10-19 подтвердила установленный 0.27.0, его receipt/payload,
24 записи backup baseline, отсутствие pending и пустой сервер. Игра и агент

Локальная проверка в контейнере без сети использовала именно совместимые
установленные workflow-исходники: два manifest, восемь payload, синтаксис hook,

истечение бюджета и сохранение диагностики при ошибке доставки ответа.

Для 0.28.0 дополнительно обязательны `summary=private_menu`, `opening_chat=0`,
`change_chat=1`; для обеих версий сохранены help `lines=5` и storage/lookup guards.
Эти статусы подтверждают запущенный вариант addon, а не внешний вид меню.

План не требует игроков, нагрузки или длительного наблюдения. Для пустого пилота
достаточны одна проверяемая установка, техническая приемка и готовый возврат
предыдущего plugin/словаря без восстановления старого vault. Дополнительные
локальные nVault-проверки для R2 уже пройдены на неизменном исходнике.
Один короткий RU/EN проход владельца после установки подтвердит меню,
цветные сообщения и сохранение настроек после переподключения.

Production-исполнение требует согласования этого конкретного bundle. Оно включает
staging и штатный dry run, единственный apply при пустом сервере, техническую
приемку и baseline reconciliation, штатный откат при подтвержденном отказе внутри
операции с сохранением текущего vault, затем итоговый evidence PR и CI/merge.
Неопределенный исход, drift, занятый сервер или отказ после terminal accepted
требуют отдельного решения. Образы, теги, API, Web и расписание backup не меняются.
