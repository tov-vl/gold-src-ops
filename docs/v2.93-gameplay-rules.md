## Scope and compatibility

`/rules` opens a private RU/EN MOTD with next-spawn `/guns` selection,
kill healing, reserve ammo refill, unchanged clips and active weapon,
reward exclusions and a reference to `/ranks`. Chat, team chat and console
aliases share an independent five-second cooldown. Dead players and spectators
can read it; invalid clients, bots, HLTV and a disabled addon receive no output.
The existing five-line `/help` includes `/rules`; the nine-item menu is unchanged.

The guide reads the current healing and ammo CVARs on every admitted request.
It uses the same healing calculation as combat: nonpositive or sub-unit amounts
disable healing, positive fractions are floored, and amounts above 100 are
clamped to 100. Ammo refill is enabled only for positive values. Each disabled
feature has an explicit translated sentence. No CVAR is changed by viewing.

The view uses the already effective language without loading player identity,
reading nVault, flushing pending preferences, refreshing standings, or changing
score, health or inventory. Combat mechanics, storage formats, rank thresholds,
API/Web and the map addon are unchanged. Client rendering is not inferred from
engine tests.
