## Corrections, Recovery And Limits

Review after rc.1 publication found that global aggregation could mix retained
Collector gauges from an older API resource with the current resource. Rc.2
selects the freshest resource before aggregating gauges/current outcomes;
historical counters and histogram rates retain previous passes. The rc.1 tag
and artifacts were preserved and never deployed.

The first isolated target test was refused because the root-created temporary
rules directory was not readable by non-root promtool. After fixing temporary
permissions, Windows native stdout corrupted non-ASCII fixture annotations;
ASCII JSON transport resolved it. Both were known isolated test failures,
with no production runtime mutation. Corrected target tests passed.

The first independent parity check compared the current API cache with the
previous OTLP observation. The existing export interval is 60 seconds; read-only
diagnostics showed a coherent preceding capture about 61 seconds behind the
new API capture, with equal availability/count. The verifier was corrected to
correlate telemetry with bounded history of actual API captures, preserving
both success-counter/time progression and strict row parity. Only read-only
acceptance was repeated; no rollout or uncertain side effect was retried.

Rollback was not required. Exact predecessor/configuration inputs remain in
the closed owner record. The existing Grafana provider forbids provisioned
panel deletion; recovery retains this read-only panel while restoring the
previous API and Prometheus rules. Old observations can remain visible during
normal lookback/expiry. No manual Grafana database mutation is planned.

No interactive login, Steam launch, gameplay-client session, backup execution,
restore, migration or personal notification was performed for this slice.
First weekly backup on 2026-10-11 at 04:00 MSK, empty server only; deferred v2.55
client acceptance and two-player play remain independent work. Complete-stack
outage cannot be detected by the same Prometheus/Grafana stack.
