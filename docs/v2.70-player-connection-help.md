# v2.70 - Player connection help

## Scope

R1, Web only: a RU/EN troubleshooting section on `/play`. Preserve static SSR,
connection data, refresh timing, clipboard behavior and the anonymous boundary.
No API, database, game, addon, authentication or backup change.

## Behavior

A link beside the connection panel opens a compact help section. Four native
HTML disclosures explain a Steam launch fallback, manual copying, the difference
between a failed server check and missing fresh observations, and first steps
after joining. Help remains available when connection data is missing and when
JavaScript is disabled. It does not invent an address or diagnose the player's
network. Links retain the selected language and focus the existing connection
panel, status-check button or first-steps section. Automatic refresh leaves
open help sections intact. No extra requests, timers or live regions are added.

## Verification and limits

Check RU/EN keyboard disclosures and focus, full-path fragment links with the
existing HTML base URL, clipboard rejection, absent connection data, no-script
navigation and 320px doubled text. Reuse public browser regressions for refresh,
localization and token isolation. Inspect representative help screenshots.
Production acceptance checks the same read-only surface after a Web-only rollout.
Launching Steam and successfully joining the game are not claims of this slice;
the game visual acceptance and two-player session remain independent.
