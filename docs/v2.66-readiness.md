## Anomalies And Limits

The initial focused run exposed a test-only Clipboard stub invocation issue;
the stub was corrected and the complete browser suite passed. Blazor query
binding selects the first duplicate value, now covered and documented.
No production failure, uncertain execution, rollback or second rollout occurred.

The language is part of the URL, independent from the in-game preference.
Navigating to an address without `lang=en` returns to Russian. Status-home and
Operator UI remain outside this localization slice. An open English page after
Web rollback rejects Russian refresh responses until a normal reload. Existing
in-memory BFF sessions retain the usual Web restart boundary; authenticated
session continuity is not claimed.

No backup, restore, migration, Steam launch, gameplay-client session or personal
notification was performed. Deferred v2.63 visual acceptance, the first
successful weekly timer cycle and two-player play remain independent.

See [contract](v2.66-public-language.md), [notes](release-notes-v2.66.md) and
[release process](release-process.md). The final evidence PR is D0 and needs no
rollout or repeated full application suite.
