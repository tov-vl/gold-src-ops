# v2.38 Bilingual Map Menu

Status as of 2026-10-05: map addon 0.2.0 and language provider 0.8.1 are installed
and accepted on the pilot. Focused local checks, required product CI and
independent external/host checks passed. Client rendering remains optional.

## Behavior

Map addon 0.2.0 uses its own RU/EN AMXX dictionary for the title, current-map
marker, exit and private vote request/unavailable messages. Weapon addon 0.8.1
exports one read-only language native; the manual choice in `/menu` applies to
`/maps` without changing client preferences or global language. An absent or
disabled provider falls back to client language: empty/ru uses Russian,
everything else English. A stale menu from the other language cannot vote.

Map names, five-map rotation, native IDs, current-map exclusion, T/CT eligibility,
cycle revalidation and engine cooldown/quorum remain unchanged. The native vote
and `timeleft` responses stay owned by the engine and are not translated here.
Stats/ranks, nVault schema-1, weapons, telemetry, queues and boot policy do not
change. No new language persistence or API/Web deployment is introduced.
