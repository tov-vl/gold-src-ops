# v2.75 - Rank progress in the public leaderboard

R1, Web only. Each valid top-10 entry shows saved enemy kills still needed for
the next rank below its current rank. Legend shows the highest-rank label.
The shared Web display catalog supplies both `/play#ranks` and leaderboard
names/thresholds; its thresholds remain checked against the addon source.

Progress uses the same snapshot as kills/rank. Stale warnings remain visible,
refresh replaces progress with the results, and expired/unavailable rows expose
no progress. An unknown rank or inconsistent rank/kill pair omits progress
rather than inventing a goal. This is a read-only display, not a change to rank
calculation, ordering, API, player saves or gameplay.

RU/EN, static SSR, keyboard navigation and enlarged mobile text are required.
No browser API call or storage is added. The scope is existing top-10 entries;
it does not add arbitrary-player lookup or identity linkage.

Deploy only the verified Web digest, retaining the previous accepted Web image
for rollback and preserving the six other containers, mounts and monitoring
files. Game visual acceptance and the first successful weekly backup remain
independent. See [readiness](v2.75-readiness.md).
