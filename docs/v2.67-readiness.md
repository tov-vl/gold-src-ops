## Evidence

- Audited restore, format and zero-warning solution build passed.
- All 970 ordinary tests passed: 614 UnitTests, 302 WebTests, 54 AlertReceiver.
- All 44 browser cases passed: 42 unchanged cases plus the two existing
  English-only dashboard cases rerun successfully with explicit lang=en.
  The new route case covers RU/EN, 1440/390/320px and no-JavaScript.
- Hardened Web container smoke passed. API/receiver container smokes are
  delegated to full CI rather than repeated locally.
- Documentation checker passed: 165 files and 954 local links.
- Read-only production baseline confirms the recorded v2.66 Web digest,
  seven running services and zero Web restarts. Private details retained.

Initial full tests failed because local Docker was stopped. After starting
Docker, all ordinary tests passed. Initial browser failures were the two old
English expectations on the now-Russian default page; explicit English URLs
preserve their original assertions. No production mutation occurred.

The first product CI passed Quality Gate and Container Smoke, but its new
320px browser check reported overflow not reproduced with the same fixture in
local Windows or isolated Linux Chromium. Layout measurement now explicitly
waits for page load and reports overflowing element bounds on failure. A new
CI result is required; no production change or acceptance is claimed.
