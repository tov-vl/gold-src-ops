## Anomalies and limits

Local Docker was initially stopped; starting it restored the integration-test
environment and all 970 ordinary tests then passed. Two old browser tests
expected English at the default URL; they now explicitly request English.

The first two product CI attempts caught a 320px layout defect. Waiting for page
load did not resolve it. Text-range inspection reproduced the fixed-size heading
with DejaVu Sans: 339.77px text extended the document to 354px while block bounds
remained inside the viewport. The heading now scales with viewport width and
can wrap; the test checks title text and document bounds. The final CI and
production browser checks passed.

The first production browser attempt read the clipboard status before the
asynchronous write completed. A bounded wait corrected the acceptance script;
the actual clipboard and all twelve scenarios then passed. The original failed
receipt was preserved. No production defect or rollback occurred.

The language belongs to the URL. Returning to a URL without lang=en selects
Russian. Game language remains independent. Operator content remains English;
login/logout contracts are unchanged. Existing in-memory BFF sessions retain
the usual Web restart boundary.

No game restart, backup, restore, migration, Steam launch or player session
was performed. Deferred v2.63 visual acceptance, the first successful weekly
timer cycle and two-player play remain independent.
