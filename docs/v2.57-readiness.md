## Recovery, Anomalies And Limits

The first launcher invocation was refused by its SSH-context guard before an
execution claim or runtime mutation: sudo did not retain `SSH_CONNECTION`.
Read-only inspection confirmed absent claim/results and both existing services
running. Passing the existing trusted SSH context retained the guard and
allowed the single claimed installation. No uncertain operation was retried.
Rollback was not needed; exact configuration backups and previous artifacts
remain available in the owner-only record.

The local installer fixture could not run in the cached engine image because
it has no jq; required PR and candidate Container Smoke ran installer/rollback
checks. Local container smoke was not repeated on unchanged source. Interactive
Auth0 login, Steam-handler launch and a game-client session were not repeated;
existing browser authorization cases passed locally and in CI. No database
restore/migration or raw production data was added to Git.

First weekly backup, deferred v2.55 real-client acceptance, two-player play and
personal notifications remain independent tasks. A fresh empty-server check is
required for any later game stop. See [the contract](v2.57-public-leaderboard.md)
and [release notes](release-notes-v2.57.md).

The final evidence change is documentation-only and requires no new runtime
rollout or repeat of an unchanged full suite.
