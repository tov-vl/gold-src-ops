# v2.60 - Актуальный статус на странице подключения

Принято 2026-10-10: stable `v2.60.0` из принятого `v2.60.0-rc.1`.

## Граница

R1, Web-only. Существующий anonymous SSR `/play` и публичная проекция API
сохраняются. Browser выполняет same-origin GET `/play` с omit credentials,
no-store и запретом redirects. Защищенный API, игровые запросы, база,
сохранения, scoring, addon, monitoring и расписание backup не меняются.

## Обновление

- Автоматический проход раз в 60 секунд в видимой вкладке; ручной доступен
  сразу, между началами запросов минимум пять секунд.
- Один запрос, timeout восемь секунд, UTF-8 HTML до 128 KiB. Неверные ответы,
  отсутствующий блок, небезопасная разметка и несогласованные controls
  отклоняются. Немедленного retry после ошибки нет.
- Возраст последней A2S проверки вычисляет Web; браузер прибавляет монотонное
  время, независимо от календарных часов клиента. Online/offline требуют
  timestamp не старше трех минут; иначе статус unknown. Карта и число игроков
  показываются только при подтвержденном online. Сетевая ошибка сразу
  делает доступность неподтвержденной и очищает эти факты.
- Известная публичная команда остается доступной при unknown/offline/ошибке
  transport. Подтвержденная unavailable проекция убирает connection controls;
  восстановление возвращает их. Успешный ответ может обновить публичный адрес.
- Документ, навигация, инструкции и refresh control сохраняются. Существующие
  Steam/copy controls обновляются на месте, сохраняя фокус. Если адрес убран
  во время фокуса на connection control, фокус переходит на refresh.
- Скрытие вкладки/уход отменяют запрос. Возврат сверяет возраст и обновляет
  по обычному расписанию. Back/forward cache возобновляет один timer.
- Без JavaScript остается SSR и обычная ссылка reload. Статус/возраст в таком
  режиме фиксированы до reload. Автообновление не запускает A2S polling.

Токены, browser storage и защищенные browser-to-API запросы не добавляются.
Пилот не обещает realtime или SLO. Старый открытый документ после rollback
может отклонить ответ прежнего Web; обычный reload восстанавливает границу.

## Проверка и recovery

Focused SSR и browser tests покрывают свежесть, состояния, recovery, focus,
clipboard, bounds, hidden/resume, timeout/overlap/cache и fallback. Полный
локальный Quality Gate, browser suite и required CI - до выпуска.
Production приемка на digest: health, независимая runtime identity, manual
и реальный минутный refresh, advancing observation, layouts 1440/390/320px,
clipboard и отсутствие browser API/credentials/storage/ошибок.

Rollback возвращает только прежний Web digest. Остальные шесть контейнеров,
полные mounts и env/config вне Web image delta сохраняются. Миграции и
game-host transition не нужны. Weekly backup, v2.55 клиентская приемка и
игра вдвоем остаются независимыми. См. [readiness](v2.60-readiness.md).
