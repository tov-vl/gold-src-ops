## Anomalies and limits

Local Docker was initially stopped, preventing 83 PostgreSQL-dependent tests
from starting. After the existing engine started, both affected suites passed.
New test-file line endings and ordinal string comparisons were corrected at
the format gate. No production failure or rollback occurred.

The 180-second expiry concerns the last recorded observation, not an uptime
promise. Aggregate last-observed time does not establish freshness for every
server. Historical counters remain labeled as the last snapshot. A transport
failure preserves historical data and connection configuration but removes
current availability claims; confirmed configuration removal removes controls.

No game restart, backup, restore, migration, Steam launch or player session
was performed. Game visual acceptance v2.63, the first successful weekly timer
cycle and two-player play remain independent. Existing in-memory BFF sessions
retain the usual Web restart boundary; no new interactive OIDC check was run.
