# v2.70 - Player connection help

Published and accepted on 2026-10-12: [v2.70.0](https://github.com/tov-vl/gold-src-ops/releases/tag/v2.70.0).

The `/play` page adds RU/EN help for Steam launch failures, manual copying,
unclear server status and the first steps after joining. Keyboard-accessible
native disclosures work without JavaScript and remain open during background
refresh. Links return to the existing connection controls and retain language.

Web-only R1. No game, API, database, authentication or backup changes.
See [contract](v2.70-player-connection-help.md) and [readiness](v2.70-readiness.md).
