## Behavior

The existing first eligible human-spawn welcome shows private saved `/rank`
progress after the command hint, once per connection/map. It does not consume
the manual `/rank` cooldown or replace another active menu. When saved stats
are unavailable, only the existing command hint is shown; no rank is invented
from an unsaved map score. Manual `/guns` keeps its existing suppression of
the automatic welcome.

A legitimate human enemy kill crossing a saved-kill tier emits one private
`Rank up` chat line to the killer, only after the existing nVault write/readback
succeeds. Later kills inside the same tier and reconnects do not repeat a
promotion. A failed readback leaves the existing session-only fallback and
suppresses the promotion message. Highest-tier progress remains bounded by
the existing counter saturation.

The [v2.35 thresholds](v2.35-player-ranks.md), scoring, Steam identity checks,
schema-1 nVault, command cooldowns, loadouts and map leaders are unchanged.
There is no separately persisted rank, XP, public broadcast, reward, HUD,
API, module, telemetry or database change. Existing saved records are neither
reset nor migrated. Aggregate operator status adds only the welcome/private
promotion policy, never player identities or records.
